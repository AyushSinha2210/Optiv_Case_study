## 1. Module Overview & Architectural Philosophy

The **Ingestion Module** is the first operational stage of the PII Guard enterprise privacy pipeline:
```
[Ingestion (Ayush)] ──> [PII Detection (Avishi)] ──> [Redaction & Gate (Yash)] ──> [Reporting & UI (Tirth)]
```

### Core Design Principles
- **Fail-Closed Default:** The public entry point `extract_document(file_path)` **never** raises an unhandled exception to the caller. Any validation failure, malformed payload, or system error safely resolves to an `ExtractedDocument` with `extraction_status="failed"` or `"partial"` and a structured, privacy-safe warning code.
- **Single Source of Truth:** `ExtractedDocument.text` is the canonical reference string for downstream PII detection and redaction. Spans generated by Member 2 and masked by Member 3 are exact zero-based, end-exclusive indices into this string.
- **Single-Pass Deterministic Normalization:** Unicode NFC, newline unification (`\r\n` $\rightarrow$ `\n`), control code filtering, and trailing space trimming occur exactly once inside this module before computing page offsets.
- **Selective OCR Fast Path:** Embedded digital text is extracted natively using PyMuPDF; OCR (Tesseract / RapidOCR) is triggered **only** for pages whose native character density falls below threshold ($\le 50$ chars) or that represent image-only scans.
- **Zero Privacy Leakage:** Log files, error traces, and structured warnings contain exclusively document IDs, warning codes, page numbers, character counts, and durations. **No document text or synthetic PII is ever emitted to logs.**

## 3. Supported Formats & Extraction Strategies

| Format | File Extension | Extraction Engine | Structural Preservation Mechanism |
| :--- | :--- | :--- | :--- |
| **Digital PDF** | `.pdf` | PyMuPDF (`fitz`) | Block-level sorting by vertical $(y)$ and horizontal $(x)$ coordinates; preserves multi-column reading order and tables without collapse. |
| **Scanned PDF** | `.pdf` | Tesseract OCR / RapidOCR | Fast-path rasterization at 200 DPI. If mean word confidence $< 60\%$, OpenCV adaptive thresholding & deskewing are applied with 300 DPI retry. |
| **Mixed PDF** | `.pdf` | PyMuPDF + Selective OCR | Hybrid per-page evaluation: native extraction where text exists; OCR only for scanned attachment pages. |
| **Word Document** | `.docx` | `python-docx` | Traverses native XML body children (`w:p` vs `w:tbl`) in true sequential document flow, interleaving paragraphs and tables; extracts headers/footers. |
| **PowerPoint** | `.pptx` | `python-pptx` | Slide-by-slide extraction: slide title first, shapes sorted by spatial coordinates, recursive grouped shapes, row-wise tables, and speaker notes marked with `--- Speaker Notes ---`. |
| **Plain Text** | `.txt`, `.text` | `charset-normalizer` | Fast UTF-8 decode with fallback to `cp1252` and `latin-1`; flags `WARN_ENCODING_REPLACEMENT_CHAR` if unicode replacement bytes occur. |

## 4. Public API & Data Contract

### Public Function
```python
def extract_document(file_path: str, config: Optional[IngestionConfig] = None) -> ExtractedDocument
```

### Data Contract Schema (`src/pii_guard/ingestion/schemas.py`)
```python
ExtractedDocument = {
  "document_id": "doc-001",            # Unique UUID identifier
  "source_type": "pdf|scanned_pdf|docx|pptx|txt",
  "text": "exact text used by downstream offsets",
  "pages": [
    {
      "index": 1,                      # 1-based index
      "label": "page|slide",           # 'page' for PDF/DOCX/TXT; 'slide' for PPTX
      "start": 0,                      # 0-based start character offset into text
      "end": 248,                      # 0-based end character offset (exclusive)
      "method": "native|ocr|mixed",    # Extraction technique used
      "ocr_confidence": 94.2,          # Mean confidence (0.0-100.0) or None
      "char_count": 248,               # Exact character count within slice
      "warnings": []                   # Page-specific warning codes
    }
  ],
  "warnings": [
    {"code": "WARN_OCR_LOW_CONFIDENCE", "page": 1, "message": "Mean confidence below threshold"}
  ],
  "extraction_status": "success|partial|failed"
}
```

### Offset Rules & Form Feed Delimiter
- Pages and slides are joined by a single form feed (`\f`, `U+000C`).
- For any page $i$:
  $$\text{slice} = \text{text}[\text{pages}[i].\text{start} : \text{pages}[i].\text{end}]$$
  $$\text{pages}[i].\text{char\_count} == \text{len}(\text{slice})$$
  $$\text{text}[\text{pages}[i].\text{end} : \text{pages}[i+1].\text{start}] == \text{"\\f"}$$

## 5. Security Controls & Configurable Defenses

All limits can be dynamically overridden via environment variables or initialized via `IngestionConfig.from_env()`:

1. **Magic Byte Signature Sniffing:** Verifies actual file headers (`%PDF-`, `PK\x03\x04`, `MZ`, `ELF`). Executable files renamed to `.pdf` are blocked (`ERR_RENAMED_EXECUTABLE`).
2. **Zip Bomb Protection:** Rejects `.docx` and `.pptx` archives exceeding a compression ratio of $100:1$ or uncompressed size $> 200\text{ MB}$ (`ERR_ZIP_BOMB_DETECTED`).
3. **Password Protection:** Intercepts encrypted PDFs and returns `ERR_PASSWORD_PROTECTED`.
4. **Hard Limits:**
   - Maximum file size: $50\text{ MB}$
   - Maximum total pages: $500$
   - Maximum OCR pages per document: $100$
   - Per-page OCR timeout: $10.0\text{ s}$
   - Total document processing timeout: $60.0\text{ s}$

## 8. Known OCR Limitations & Mitigations

1. **Low-Resolution / Heavy Artifact Scans:** Text with severe scanning noise or DPI $< 150$ can yield lower word confidence.  
   *Mitigation:* Automated fallback pipeline applies OpenCV adaptive Otsu binarization and deskewing, retrying at 300 DPI, and surfaces `WARN_OCR_LOW_CONFIDENCE` with `extraction_status="partial"`.
2. **Complex Multi-Column Scanned Tables:** Table borders in rasterized images may lead OCR engines to concatenate cells horizontally.  
   *Mitigation:* Digital PDFs extract table structures via PyMuPDF coordinate blocks, while scanned pages preserve row-by-row lines.
3. **Handwritten Annotations:** Tesseract is tuned for printed typography; cursive handwriting returns lower confidence scores and is flagged for human review.
